SurBox for Windows — experimental native x64 build

Requires Windows 10/11 x64. Extract the ENTIRE ZIP, then run SurBox.exe.
Keep the samples folder next to the executable. No installer, account, runtime
sample download, microphone or cloud service is required.

Drag the rear bellows panel up/down. Play keys with the mouse or use:
A W S E D F T G Y H U J K O L P ; '
Hold Space to pump; Escape releases all notes. Left/Right shift octave.
Volume, air assist, sensitivity, tonic, practice scale and Sa/Pa drones are
available in the toolbar. Click the instrument after changing a control to
return computer-keyboard focus. Notes stop on focus loss/deactivation.

Physical laptop-lid angle tracking is NOT supported on Windows.
This app is unsigned (no Authenticode certificate). Windows SmartScreen may
warn. Use only if you trust the source; do not disable security globally.

This binary was cross-compiled on macOS. Unless the accompanying current
platform test report says otherwise, actual Windows GUI/audio/device testing
is NOT verified. This is an experimental download, not a stable release.
Run SurBox.exe --self-test to write windows-self-test.txt and validate the
sample loader and DSP inside a Windows process. That is not a speaker test.

Audio: Donya Quick, Freesound #330410, CC0 1.0. 39 acoustic note derivatives
from the HQ MP3 preview, with pitch correction, looping and envelopes.
Missing recordings select an explicitly labeled synthetic reed fallback.
See Audio-LICENSE.txt. Decorative stops are not separate sampled reed banks.
