SurBox engineering previews — Android 1.0.1 / macOS and Windows 1.0.0

ANDROID 1.0.1 — LARGER PLAYABLE KEYS
Responds to feedback that the original perspective keys were too small/thin.
Now shows 13 tall, wide keys, with no perspective compression on touch faces.
The bellows moves in a separate compact upper band; one toolbar frees height.
Octave controls preserve the previous C2-C8 reach. Natural/black hit regions
match the visible keys and stay fixed during pressed animations. Minor finger
jitter near natural-note boundaries no longer changes pitch accidentally.
Signed with the same release key; install over 1.0.0. VersionCode is now 2.
The macOS and Windows packages are unchanged by this Android-specific fix.

New native ports, not browser wrappers:
- Android: Java/Canvas perspective bellows, multitouch chords and AudioTrack.
- Windows: Win32/GDI perspective bellows, keyboard/mouse and native PCM output.
- Both use the 39 bundled CC0 acoustic recordings, independent note ownership,
  constrained fixed hinge, accordion pleats, bidirectional air reserve, volume,
  air assist, tonic, scale guides, Sa/Pa drones and note-release safety.
- Android uses a landscape-first layout. Windows is portable: extract the entire
  ZIP and keep the samples folder next to SurBox.exe.
- Existing native macOS app is retained.

VERIFIED
Android: 29 native checks pass at both normal and compact landscape emulator

upgrade and signature verification pass. Physical finger comfort is unverified.
Windows: MSVC build on actual Windows runner; 13 native UI checks, sample/DSP
process check and 13 C++ core assertions pass. Public ZIP is that runner build.
macOS: previous 16 deterministic groups and 53 primary native checks remain.
Full reports: platform-testing.txt, verification.txt and lid-tracking.txt.

LIMITATIONS
All downloads remain engineering previews. Windows and Android do NOT read
physical laptop/foldable lid angles. Use touch/mouse or Space to pump.
macOS physical lid input requires exposed compatible hardware. The development
2020 M1 Air has no such continuous sensor. Actual compatible-hardware movement
remains unverified; injected tests are not physical sensor evidence.

Android is signed for direct installation, not distributed through Google Play.
Windows is not Authenticode signed; SmartScreen may warn. macOS is ad-hoc signed,
not Developer ID signed or notarized. Use only downloads you trust and the normal
OS approval flow. Never disable OS security globally.
Physical hardware listening, end-to-end latency, assistive technology, device
switching, old OS versions and long-run thermal/battery testing remain open.
No iOS, Linux, Windows ARM-native or macOS Intel binary is supplied.

This website distributes files; the instrument does not run on Vercel.
No account, microphone permission, paid API or internet is needed to play.
